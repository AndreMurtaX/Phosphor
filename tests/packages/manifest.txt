# Opt-in host package suite manifest. Read by test-packages.{ps1,sh}.
# 02_sqlite is conditional: run only where the SQLite runtime library is present.
# 03_http runs against a local server the runner (phosphorhttptest) stands up.
# 04_https is conditional: run only where the OpenSSL runtime can be loaded.
# 05_crt exercises the console-control (CRT) package -- ANSI escape sequences.
# 06_archive exercises zip (handle create/add/list/extract), gzip (string+file
# round-trips, size/ratio) and base64 file encode/decode; all ship with FPC.
# 07_sqlite_full is conditional (same runtime-library gate as 02_sqlite): the full
# statement-level surface -- prepared statements, binding, a cursor with column
# metadata, transactions, JSON row/table introspection, changes/lastid, errors.
# 08_http_offline is the HTTP client's OFFLINE half: a client-config accumulator
# (base url, headers, params, cookies, auth, proxy, behaviour flags), a multipart
# form (fields + files + url-encoded render) and the pure url/html encoders. No
# network: it routes to phosphorhttptest (the name has "http") and ignores the
# standing server. Plain-HTTP config needs no external library, so it runs everywhere.
